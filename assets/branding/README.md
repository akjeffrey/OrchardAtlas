# OrchardAtlas original Option 1 icon

These PNGs are crops/resizes of **Option 1 — Modern Map Tree** from the original five-icon concept board, not a regenerated interpretation.

Use `orchardatlas_option1_original.png` as the 1024x1024 source asset. The original concept has rounded corners and background/shadow as part of the image; for production adaptive Android icons, a separate foreground and background design is recommended.
